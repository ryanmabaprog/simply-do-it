# Simply Do — Frontend

O frontend consome a API em `http://localhost:3000` por padrão. Inicie a API e sirva esta pasta com qualquer servidor estático:

```bash
cd packages/frontend
python3 -m http.server 5173
```

Abra `http://localhost:5173` no navegador. Para usar outra URL da API, acrescente `?api=https://sua-api.exemplo.com` ao endereço.
